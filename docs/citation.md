# Citation

If you use hgt-site in your work, please cite it. Every release is archived on Zenodo with its own DOI, and the DOI below always points to the latest version:

[10.5281/zenodo.23842712](https://doi.org/10.5281/zenodo.23842712)

The GitHub page has a "Cite this repository" button, which reads [CITATION.cff](https://github.com/iraajgangavaram/hgt-site/blob/main/CITATION.cff) and offers APA and BibTeX.

## Tools hgt-site builds on

- Kraken2, for the per-read classifications: Wood, Lu and Langmead (2019), *Genome Biology* 20:257.
- pysam, for reading BAM and CRAM files.
- nf-core/hgtseq, whose outputs hgt-site reads directly: Carenzo et al. (2023), *NAR Genomics and Bioinformatics* 5:lqad028.
